# 📊 Customer Churn Analysis

## Project Overview

Analysis of customer churn patterns for a Telco company using Python.
Dataset contains 7,043 customers across 21 variables.

## Key Findings

| Factor               | Finding                            |
| -------------------- | ---------------------------------- |
| Overall Churn Rate   | 26.54% — 1 in 4 customers left     |
| Contract Type        | Month-to-month had highest churn   |
| Internet Service     | Fiber optic customers churned most |
| Avg Tenure (Churned) | 17.98 months vs 37.57 for loyal    |
| Avg Monthly Charges  | $74.44 churned vs $61.27 loyal     |

## Tools Used

- Python, Pandas, Matplotlib
- Jupyter Notebook (VS Code)

## Dataset

- Source: Kaggle — Telco Customer Churn
- Size: 7,043 rows × 21 columns
